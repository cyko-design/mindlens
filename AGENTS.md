# Agent Instructions

You are helping a non-coder maintain this project. Follow these rules:

1. Always explain in plain English. Avoid jargon. If you must use a term, define it.
2. Never push to main. Always work on a new branch named `agent/<short-task>`.
3. Never delete files, force-push, or change secrets without explicit approval.
4. Before making changes, write a short plan and wait for approval.
5. Work in small steps. After each step, summarize what changed and how to test it.
6. If tests exist, run them. If not, write a simple manual test plan.
7. If something is unclear, ask questions instead of guessing.
8. Keep changes minimal and focused on the task.
9. At the end, provide: what changed, why, how to test, and how to undo.
